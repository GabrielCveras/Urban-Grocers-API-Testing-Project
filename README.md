# Urban-Grocers-API-Testing-Project

Projeto de Quality Assurance (QA) realizado durante minha formação em testes de software, com foco na validação de novos recursos da API do Urban.Grocers.

O projeto envolveu analisar os requisitos e a documentação da API, elaborar um checklist, testar os endpoints no Postman e registrar possíveis bugs no Jira.

## 🎯 Objetivos do Projeto

Analisar os requisitos do back-end e a documentação da API.

Projetar verificações para os novos recursos da API.

Testar a inclusão de produtos em kits.

Verificar a disponibilidade e o custo do serviço de entrega Order and Go.

Comparar os resultados reais com os resultados esperados.

Documentar bugs encontrados e, como atividade extra, preparar um relatório de teste.

## 🔌 Testes de API / Backend

### Funcionalidades testadas:

Adicionar produtos a um kit pelo endpoint POST /api/v1/kits/{id}/products.

Verificar a disponibilidade e calcular o custo da entrega Order and Go pelo endpoint POST /order-and-go/v1/delivery.

### Atividades realizadas:

Análise dos requisitos do back-end e da documentação da API.

Criação de um checklist para cobrir os novos recursos.

Execução das requisições no Postman.

Validação das respostas e comparação com os resultados esperados.

Registro dos resultados na planilha do projeto.

Reporte de bugs encontrados no Jira.
